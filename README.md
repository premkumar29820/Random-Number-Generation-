# Random Number Generator

A simple and interactive **Random Number Generator** built using **React.js**. This project generates random numbers instantly with a single click, demonstrating the fundamentals of React, state management with Hooks, and event handling.

## 🚀 Features

* 🎲 Generate a random number with one click
* ⚛️ Built with React functional components
* 🪝 Uses the `useState` Hook for state management
* ⚡ Instant UI updates without page refresh
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS

## 🎯 Learning Objectives

* Understand React functional components
* Learn state management using the `useState` Hook
* Practice event handling in React
* Generate random values using JavaScript
* Build interactive web applications
